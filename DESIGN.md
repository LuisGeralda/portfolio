# Ink & Grid portfolio

Adapted from Luis's supplied design-guidelines package for an engineering portfolio.

- Warm paper `#F4F2EE`, ink `#111111`, graphite `#5A5752`, rule `#D6D2CA`, and signal red `#E5341F`.
- Instrument Serif carries editorial headlines; Inter carries body text; Geist Mono carries labels and metadata.
- A 12-column desktop grid with hanging section labels becomes a single readable content column on phones.
- Hairline separators, square diagrams, minimal button rounding, no decorative gradients.
- Red marks the decisive step in each independent architecture or sequence figure. It is not used for small text.
- Body copy is at least 16px. UI metadata, figure labels, technology lists, captions, and control text use smaller sizes appropriate to their roles.
- Small diagram labels are schematic metadata, not prose. Diagrams carry accessible labels and prose explanations.
- Font loading has system fallbacks. Commercial licensed font files are not shipped.
- The walkthrough is user-controlled. Smooth anchor scrolling respects reduced motion. Important rules for hidden content and reduced motion deliberately override competing styles.
- Dark mode retains the same typography, spacing, and semantic color roles.
